Default sources, sinks and sanitizers for the pipeline's automatic first engine run, one file per YASA
language. Extracted from YASA-Engine `resource/example-rule-config/rule_config_{js,java,python,php}.json`
(https://github.com/antgroup/YASA-Engine, commit 59d2234, Apache License 2.0), keeping only the block of
the named checker. The builder agent replaces or extends them for the project.
